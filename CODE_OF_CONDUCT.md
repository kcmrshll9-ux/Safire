# Code of Conduct

## Our standard

Safire project spaces should be welcoming, constructive, and safe. Participants are expected to:

- communicate with respect and patience;
- critique ideas and code without attacking people;
- welcome relevant questions and differing experience levels;
- protect private information and use synthetic vault data in public reports;
- disclose conflicts of interest that affect a contribution or review; and
- accept moderation decisions intended to protect the project and its participants.

Unacceptable behavior includes harassment, threats, discrimination, sexualized attention, deliberate disruption, doxxing, publishing private vault content, or encouraging others to evade project licensing and security boundaries.

## Scope

This code applies to issues, pull requests, reviews, discussions, and other spaces represented as part of the Safire project. It also applies when someone represents the project in a public setting.

## Reporting

For an immediate GitHub platform violation, use GitHub’s built-in block and report controls. For a project conduct concern that should remain private, use the private reporting path in [SECURITY.md](SECURITY.md) and identify the report as a **Code of Conduct concern**. Do not include sensitive details in a public issue.

## Enforcement

The repository owner is responsible for clarifying and enforcing this standard. Proportionate responses may include a private correction, removal of content, a warning, temporary participation limits, or a permanent ban. Reports will be handled as privately as practical, subject to safety and legal obligations.

Retaliation against someone who raises a good-faith concern is itself a violation.
