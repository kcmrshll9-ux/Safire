Safire

A calm knowledge forge for notes, ideas, projects, links, daily logs, and connected thinking.

Safire 1.3.4 stores notes as plain Markdown files on your computer. Its focused workspace adds tabs, search, backlinks, an interactive relationship graph, tasks, templates, web capture, daily notes, and recoverable edits.

Five-minute Quick Start

1

Create a note

Click + Note, type a title or folder path such as Projects/My Plan, then write in Markdown.

2

Link your ideas

Type [[Ideas]] or [[Project Plan]]. In preview, click a missing link to create it.

3

Use tags

Add tags like #home, #client, or #daily. Safire collects them in the left sidebar.

4

Move fast

Use Ctrl+K for commands, Ctrl+O to jump to notes, and Ctrl+S to save.

How notes connect

Feature Map

File tree

Organize notes in folders. Safire stores everything as normal Markdown files.

Tabs

Keep multiple notes open and move between them quickly.

Backlinks

See which notes point to your current note.

Interactive Graph

Explore note relationships through a two-dimensional force layout with local/global modes, filters, groups, pan, zoom, and node dragging.

Daily Notes

Click Today to open or create today’s log.

Autosave

Your writing is saved automatically. Manual save is always available.

Markdown Toolbar

Format headings, bold, links, tasks, quotes, code, and wikilinks without memorizing Markdown.

Backups & Restore

Preview and restore backup versions created before saves and deletes.

Attachments

Drag, paste, or attach files into the vault and insert Markdown links automatically.

Settings

Control autosave, startup note, default view, daily folder, and backup retention locally.

Where your files live

In the standalone app, your notes live in:

Documents/Safire Vault

Safire uses the vault selected during desktop setup. Developer runs can set SAFIRE_VAULT_PATH explicitly. Because notes are ordinary Markdown files, a full-vault copy is a practical independent backup.
