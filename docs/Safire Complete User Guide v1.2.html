1. Safire at a glance

Safire is a desktop knowledge workspace that keeps your notes as normal .md files on your own computer. You get a polished writing environment without giving up file portability or control.

Local-first

Notes, preferences, backups, templates, and attachments stay inside your vault. You can copy or back up the vault like any other folder.

Connected thinking

Wikilinks, backlinks, tags, search, a graph view, and a note outline make related ideas easy to find.

Practical workflows

Use a Home dashboard, vault-wide tasks, quick capture, daily notes, templates, saved searches, pinned notes, and recent notes.

Safety built in

Safire backs up a note before replacing it, deleting it, toggling a task, or restoring a prior version.

Where the data lives: Safire uses the vault selected during desktop setup. A developer/browser run can set SAFIRE_VAULT_PATH explicitly. Notes remain ordinary Markdown files in that folder.

What Safire is not

Safire is not a cloud-sync service. Keep an independent backup of your vault using the backup system you trust. Safire is an original application and is not affiliated with, or a copy of, any proprietary notes app.

2. Quick start

Choose your vault during setup

On the first desktop launch, Safire asks where it should keep your Markdown notes. Choose the recommended Documents/Safire Vault location or select an existing or new folder. Safire remembers this choice.

Launch Safire

Open the Safire desktop application. For a developer/browser run, use npm start in the Safire project folder, then open http://127.0.0.1:5277.

Open or create a note

Select a note in the Files panel, or choose + Note. You can enter a simple title or a path such as Projects/Quarterly Plan.

Write in Markdown

Write normally in the editor or use the toolbar to insert headings, bold text, tasks, web links, wikilinks, code, quotes, lists, and attachments.

Connect ideas

Type [[A Related Note]]. Safire displays outgoing links and backlinks, and graph view lets you explore the relationships visually.

Build a habit

Use Today for a daily log, Quick capture for a fast Inbox note, and the Home dashboard to resume useful work.

Saving

Safire saves automatically when Autosave is enabled. Use Ctrl + S whenever you want an immediate save. Replacing an existing note creates a dated backup first.

Tip: Start with a short daily note, then use wikilinks instead of trying to organize everything perfectly up front. Links and search will keep the vault navigable as it grows.

4. Notes and Markdown

Create, rename, move, and delete

  1. Select + Note and enter a title or a vault-relative path. Safire adds .md as needed.
  2. To move a note, choose Rename and enter a new path, for example Projects/2026/Plan.md.
  3. To delete a note, choose Delete and confirm. Safire creates a backup before the deletion.
Be deliberate with delete: Safire’s backups help with recovery, but they are not a replacement for your normal backup routine.

Markdown toolbar

View modes

Use Split to write and see formatting at once, Edit for uninterrupted Markdown, Preview for reading, and Graph to inspect vault connections.

Note outline and reading stats

Use Markdown headings to create an automatic outline in the Inspector. Select an outline entry to scroll the preview to that heading. Safire also reports word count and estimated reading time for the active note.

5. Connected knowledge

Folders and tags

Create folders with + Folder or by using a folder path when creating a note. Add tags directly in note text, such as #projects, #home, or #research. Selecting a tag in the sidebar searches for it.

Search and saved searches

The search field looks through note paths and note content. After entering a useful query, choose Save search; it will appear on Home until you remove it.

Wikilinks and backlinks

  • Write [[Project Plan]] to link by note title.
  • In preview, select a linked note to open it. If the linked note does not exist, Safire can offer to create it.
  • Outgoing links show notes named by the current note.
  • Backlinks show notes that point back to the current note.

Graph view

Graph view arranges notes by connection density. Solid connections are resolved links; dashed connections represent unresolved links. Select a graph node to open the corresponding note. To keep large or adversarial vaults responsive, Safire applies fixed note, link, and unresolved-placeholder limits and displays a notice with source and rendered note counts whenever a graph is truncated. Link counts that stop before all omitted notes are scanned are explicitly labeled as lower bounds.

Useful pattern: Write first, link second. When you mention a person, project, place, or repeated idea, type a wikilink. Over time the graph becomes more useful without an elaborate folder scheme.

6. Home, tasks, capture, daily notes, and templates

Home dashboard

Home surfaces open tasks, pinned notes, recently opened notes, saved searches, and vault health. It is the fastest way to resume productive work.

Pin a note

Select Pin in the active note’s header. Pinned notes stay visible on Home until you unpin them.

Vault-wide tasks

Use Tasks to see open or completed Markdown checklist items across every note. Select the checkbox to toggle a task, or its title to open the note at its source.

Quick capture

Use Quick capture to save a thought into a new portable Markdown note in Inbox/. Add an optional simple tag.

6. Continued: daily notes and templates

Daily notes

Select Today to open or create Daily Notes/YYYY-MM-DD.md. The starter layout includes Notes, Tasks, and a #daily tag. Change the daily-note folder in Settings if you prefer another location.

Templates

  1. Create one or more Markdown files under Templates/.
  2. Use Home or the Command Palette and select New from template.
  3. Choose a template, set the destination path, optionally set a title, then create the note.

Templates are ordinary Markdown. Safire substitutes {{title}}, {{date}}, and {{time}} when it creates the new note.

Example meeting template

# {{title}}

Date: {{date}} {{time}}

## Agenda

## Notes

## Follow-up
- [ ]

Command palette and quick switcher

Use the Command Palette to run Safire actions from one searchable list. Use Quick Switcher to jump directly to a note. Both support filtering, arrow-key selection, Enter to choose, and Esc to close.

7. Attachments, images, and media

Add an attachment

Select Attach or Attach file, drag files into the editor, or paste a file into the editor. Safire stores the file under Attachments/ and inserts Markdown automatically.

  • Images are inserted with Markdown image syntax and display in Preview.
  • Other supported files are inserted as Markdown links.
  • Safire limits one uploaded attachment to 15 MB.

Attachment viewer

Select an attachment in Preview to open it inside Safire. The viewer has prominent Back to Safire and close controls, and Esc also returns to the note. Use Download file when you need the original outside the app.

7. Continued: image controls and rich links

Image sizing

Select an image in Preview to open the Image size menu. Choose Small, Medium, Large, Full width, Original, or Use default. Per-image choices are stored in portable Markdown as a compact size marker; the global Fit images to page setting controls the default behavior.

YouTube links

When a normal YouTube URL appears in a note, Safire renders a local-only card without downloading a thumbnail or embedding a player. YouTube is contacted only after you open the link. The desktop content policy blocks remote Markdown images; attach an image to the vault when it should appear in Preview.

Attachment safety: Safire only accepts attachment paths under the vault’s Attachments/ folder and keeps preview navigation inside the app whenever possible.

8. Web Clipper

The Web Clipper saves a public web page as durable, offline-readable Markdown in your vault. It is designed for research material, recipes, references, articles, and academic papers—not as a cloud service.

Capture a page

  1. Open Web Clipper from the ribbon or Command Palette.
  2. Paste a public http or https URL.
  3. Optionally enter a title override.
  4. Choose a built-in or custom template, then select Capture page.

8. Continued: Web Clipper safety and custom templates

Web Clipper safeguards

  • Only public http and https pages are accepted.
  • Safire blocks localhost, private-network, and .local addresses.
  • Redirects are rejected.
  • Fetches have a 15-second limit and pages larger than 2 MB are rejected.
  • Only HTML responses are captured.

Custom templates

Select + Custom template in Web Clipper to save a reusable Markdown layout under the local .safire/ settings folder. Each custom template specifies a name, ID, destination folder, description, and Markdown body.

TokenReplaced with
{{title}}The page or overridden title.
{{url}}The original source URL.
{{author}}Available author metadata.
{{description}}Available page description.
{{captured_at}}Safire’s capture timestamp.
{{content}}Readable captured Markdown content.
{{citations}}Collected citation links.
{{footnotes}}Collected footnotes where available.
Practical note: Capture public material that you are permitted to save and use. The quality of a clip depends on the page’s publicly available HTML and metadata.

9. Continued: backups, vault health, and privacy

Backups and restore

Safire writes dated backups under .safire-backups/ before it replaces a note, deletes a note, toggles a task, or restores a backup. To review history:

  1. Open the note and select Backups.
  2. Choose an item to preview its contents.
  3. Select Restore this backup only after checking the preview.
  4. Safire creates a safety backup of the current note before the restore.

Vault health

The Inspector summarizes note, tag, link, and backup counts. It also identifies unresolved wikilinks and orphan notes. Use it as a light-weight cleanup signal—not as a reason to remove useful standalone notes.

Privacy and local access

  • The Safire local API binds to 127.0.0.1 by default rather than your network.
  • Paths are validated to prevent reads/writes outside the vault.
  • Attachments must live beneath Attachments/; backup IDs must stay beneath .safire-backups/.
  • Notes remain plain Markdown files. Copying the vault folder is a practical whole-vault backup.
Recommended backup routine: Close Safire if needed, then copy your entire Safire Vault folder to a trusted external drive or backup service. Keep at least one backup separate from the computer.

10. Hermes native integration

Safire v1.2 adds a local MCP (Model Context Protocol) server. It lets Hermes work directly with the vault through narrow, explicit tools instead of attempting to operate the visual app interface.

More reliable

Hermes communicates with a local Safire service and receives structured results. It does not depend on screen coordinates, windows, or visual menus.

Scoped by design

The integration only exposes practical note and task actions. High-risk or broad functions are intentionally absent.

10. Continued: using Hermes with Safire

The optional Safire MCP server can be registered with a compatible client. It reads the same saved vault choice made during desktop setup, so the app and client can work with one vault. Start a new client session after changing tool configuration so discovery can run again.

Available Safire tools

List / search notesLists note metadata or searches paths and note contents.
Read noteReads one Markdown note by vault-relative path.
Create noteCreates a new note and refuses to overwrite an existing file.
Update noteCreates or replaces a note; replacing an existing note backs it up first.
Quick captureSaves a short thought into a new Inbox note, optionally tagged.
List tasksLists open, completed, or all Markdown checklist tasks across the vault.
Toggle taskChecks or unchecks a known task by note path and line; Safire backs up the note first.
Vault healthReports note, tag, link, missing-link, orphan-note, and backup information.

What the integration does not expose

For safety, it does not provide delete, rename/move, attachment access, backup restore, settings changes, or web-fetch/web-clipping tools. Use Safire’s normal interface for those actions.

Example requests

  • “Search Safire for notes about the August training plan.”
  • “Read Projects/Launch Plan.md and summarize its open tasks.”
  • “Create a Safire note at Inbox/Ideas.md with these bullets…”
  • “Add this approved text to Projects/Status.md.”
  • “Show my open Safire tasks.”
Writing is still an action: Be explicit when you want Hermes to create or change a note. Ask it to search or read when you only want information. Existing notes are backed up before an MCP update, but it is still best to state the intended file and change clearly.

10. Continued: how the integration is configured

Safire’s MCP server runs locally through safire-mcp.mjs, uses an in-process vault service over stdio, and opens no HTTP listener. It uses the vault chosen during desktop setup. Change the selection later through Safire → Change Vault Location…; then start a new Hermes session so it reconnects to that shared choice.

In a standard Hermes configuration, the server is represented as a local stdio MCP entry similar to this:

mcp_servers:
  safire:
    command: node
    args:
      - <absolute-path-to-safire>/safire-mcp.mjs
    timeout: 30

Replace the placeholder with the local repository path. Configuration syntax and trust controls vary by MCP client.

If Hermes cannot see Safire tools

  1. Start a new Hermes session. Tool changes do not appear in the session that was already open.
  2. Check the server with hermes mcp test safire from a terminal.
  3. In Safire, use Safire → Open Vault Folder to confirm the chosen vault is the one you intend to use.
  4. Run hermes mcp list to verify that safire is enabled.

12. Troubleshooting and reference

SituationWhat to do
Safire does not openLaunch it again. In developer/browser mode, run npm start and check http://127.0.0.1:5277.
A note seems missingSearch by title or text, inspect the Files tree, then check the vault folder directly. Look in Backups before assuming the content is gone.
Preview looks staleSave the note, refresh or restart the app, and switch views. In browser/developer mode, use a cache-busting reload if a service worker has an old asset cached.
An attachment does not openUse the attachment viewer’s Download file control and confirm the file exists beneath Attachments/.
A task is not shownUse the supported checklist form - [ ] Task or - [x] Done. Tasks inside fenced code blocks are intentionally ignored.
Web Clipper failsUse a public HTML page. Safire rejects local/private addresses, redirects, non-HTML content, oversized pages, and slow fetches.
Hermes cannot use SafireStart a new Hermes session, then run hermes mcp test safire if needed. Verify the enabled status and vault path.
