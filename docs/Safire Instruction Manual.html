1. Overview

Safire is a desktop knowledge workspace that stores your writing as normal .md Markdown files on your computer. It is designed to feel polished and app-like while keeping your information readable, portable, and under your control.

Local-first

Your notes live in a folder called a vault. They remain ordinary files that can be backed up, copied, searched, or opened outside Safire.

Connected thinking

Use [[wikilinks]], backlinks, outgoing links, tags, and graph view to connect notes into a living knowledge map.

Writing flow

Use split view, preview view, edit view, tabs, autosave, command palette, quick switcher, and Markdown toolbar shortcuts.

Trust features

Safire creates backups before writes/deletes and includes a backup browser with preview and restore.

2. Quick Start

Launch Safire

Open the Safire desktop app. If you are using a developer/browser run, start the server from the project folder with npm start and open http://127.0.0.1:5277.

Choose or confirm your vault

Safire uses the vault selected during desktop setup. Developer/browser mode can set SAFIRE_VAULT_PATH explicitly.

Create your first note

Click + Note, enter a name, and start typing. Safire automatically appends .md when needed.

Link ideas together

Type [[Ideas]] or use the Wiki toolbar button. Links appear in preview and can create missing notes.

Use commands

Press Ctrl + K for the command palette or Ctrl + O for the quick switcher.

Local service: Safire's application service binds to 127.0.0.1, so it is intended to be reachable only from the same computer.

4. Creating & Editing Notes

Create a note

  1. Click + Note.
  2. Enter a title or path, such as Projects/Safire Ideas.
  3. Click Create note.

Rename or move a note

Click Rename and enter a new path. Including a folder path moves the note, for example Projects/Ideas.md.

Delete a note

Click Delete. Safire asks for confirmation and creates a backup copy before deletion.

Important: Although Safire creates backups, keep a separate backup of your vault folder using your normal PC backup method.

6. Folders, Tags & Search

Folders

Click + Folder to create vault folders. Notes can be nested inside folders by naming them with a path.

Tags

Type tags directly in notes, such as #project, #daily, or #ideas. Safire collects tags into the sidebar tag cloud.

Search

Use the sidebar search box to search note names and note content. Clicking a result opens the note.

7. Wikilinks, Backlinks & Graph

Wikilinks connect notes by title. For example, typing [[Project Plan]] creates a clickable link to a note named Project Plan.md.

  • Outgoing links show notes that the current note points to.
  • Backlinks show notes that point back to the current note.
  • Graph view shows a visual map of note relationships.
Tip: Use wikilinks liberally while writing. You can create missing notes later by clicking unresolved links in preview.

8. Attachments

Safire can copy files into the vault and insert Markdown links to them.

Add an attachment

  1. Click Attach or Attach file, or drag/drop a file into the editor.
  2. Safire copies the file into the vault's Attachments/ folder.
  3. A Markdown link is inserted into the note.

Open an attachment

Click the attachment link in preview. Safire opens the file in an in-app attachment viewer so the note app stays open. Use Back to Safire, the close button, or Esc to return to your note.

Image attachments

Images are inserted as Markdown image links and display in preview.

10. Backups & Restore

Safire creates dated backup files before note saves and deletes. These backups are stored under .safire-backups/ inside the vault.

Preview backups

  1. Open a note.
  2. Click Backups.
  3. Select a backup from the list to preview its content.

Restore a backup

  1. Select a backup.
  2. Click Restore this backup.
  3. Confirm. Safire creates a safety backup of the current note first, then restores the selected version.

12. Privacy & Safety

  • Safire stores notes as plain Markdown files in your chosen vault folder.
  • The local API binds to 127.0.0.1 by default.
  • File APIs reject path traversal outside the vault.
  • Backups are created before writes/deletes.
  • Safire is not a cloud sync service. If you need off-device backup, use a backup tool you trust.

13. Troubleshooting

IssueSuggested Action
The app does not openTry launching the app again. In developer mode, run npm start and confirm http://127.0.0.1:5277 responds.
A note seems missingCheck the file tree, search by title/content, and inspect the vault folder directly.
A link creates the wrong noteCheck spelling and capitalization of the wikilink target. Rename the note if needed.
Attachment does not previewUse the Download file link in the attachment viewer and verify the file exists in Attachments/.
Need to recover old textOpen Backups, preview previous versions, and restore the correct one.
Preview looks staleSave the note, refresh the app, or switch views. In browser/dev mode, a service worker cache may need a cache-busting reload.
