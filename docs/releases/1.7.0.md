Safire 1.7.0 brings protected writing, connected projects, and a practical research desk into one consistent local workspace.

## Highlights

- **Protected drafts:** Keep unsaved writing through navigation, reloads, and desktop restarts. Recover it from Home.
- **Confident saves:** Compare external changes, preserve your version as a copy, or review a merge. Typing during a save stays protected.
- **A consistent interface:** Warm paper and forest green in light mode; deep forest and gold in dark mode. Editor, projects, graphs, tasks, capture, settings, and Help now belong together.
- **Connected notes:** Preview wikilink updates before renaming or moving a note, with backups of changed files.
- **A larger library:** Incremental, paged search across up to 100,000 notes, with clear capacity notices and a rebuildable local catalog.
- **Research that travels:** Capture sources, review evidence, and export Markdown or designed HTML briefs with receipt-free prose and permitted public source URLs.

## Security and reliability

This release fixes five source-review findings: linked configuration files, unbounded fetched web content, case-equivalent API origin checks, local receipt paths in report excerpts, and internal memory digests in retrieval projections. Compatible dependency patches resolve the advisories found during release preparation. Focused regression tests accompany the fixes.

## Updating

Your selected vault and Markdown files remain in place. The search catalog rebuilds its projection automatically. New draft checkpoints live under `.safire/drafts`; they are local plaintext, like notes and backups. Backups are kept until manually removed.

The library and the older graph/task/MCP projections have different capacity limits; see the [workspace guide](https://github.com/kcmrshll9-ux/Safire/blob/v1.7.0/docs/PRODUCT_WORK.md). This release does not add cloud sync, accounts, or automatic transcript capture.
