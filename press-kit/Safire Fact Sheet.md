## One-line description

Safire is a local-first Markdown knowledge forge for connected notes, interactive relationship mapping, focused daily workflows, and recoverable edits.

## Key features

- User-selected, filesystem-backed Markdown vault
- Split Markdown editor and sanitized preview
- Folders, nested notes, tabs, full-vault search, tags, and saved searches
- Wikilinks, backlinks, outgoing links, and missing-note creation
- Interactive two-dimensional, force-directed relationship graph
- Global and local graph modes, filters, grouping, hover highlighting, pan, zoom, and node dragging
- Home dashboard, daily notes, vault-wide tasks, quick capture, and templates
- Drag, paste, and attach files into the vault
- Web Clipper with local/private-network request protections
- Command palette and quick switcher
- Autosave controls and per-vault settings
- Backup browser with preview and guarded restore
- Local service bound to the loopback interface
- Optional local Model Context Protocol integration

## Privacy posture

Safire does not provide hosted sync or telemetry. The core note workflow stays on the user's computer. Web Clipper requests a public URL only when the user initiates a capture, and some rich media previews may request remote thumbnails. Users are responsible for their chosen backup and synchronization tools.

## Positioning

Safire is for people who want a polished connected-notes workspace while keeping their writing in durable, portable Markdown files.
