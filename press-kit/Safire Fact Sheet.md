## One-line description

Safire is a Markdown knowledge forge for connected notes, interactive relationship mapping, focused daily workflows, and recoverable edits.

## Key features

- User-selected, filesystem-backed Markdown vault
- Split Markdown editor and sanitized preview
- Folders, nested notes, tabs, full-vault search, tags, and saved searches
- Wikilinks, backlinks, outgoing links, and missing-note creation
- Named projects built from top-level vault folders, with project entries kept out of the Home index until a project is opened
- A separate two-dimensional, force-directed relationship graph for each project, limited to that project's notes and internal links
- Project-relative folder clusters and wikilink resolution, plus project and local scopes, filters, grouping, hover highlighting, pan, zoom, and node dragging
- Daily notes, vault-wide tasks, quick capture, and Markdown templates
- Drag, paste, and attach files into the vault
- Web Clipper with local/private-network request protections
- Command palette and quick switcher
- Autosave controls and per-vault settings
- Backup browser with preview and guarded restore
- Local service bound to the loopback interface
- Searchable in-app Help with complete workflows, AI-assistant connection examples, troubleshooting, privacy guidance, MIT licensing, and third-party notices
- Optional local Model Context Protocol integrations for the eight-tool Markdown vault and separate six-tool attributed agent memory

## Privacy posture

Safire does not provide hosted sync or telemetry. The core note workflow stays on the user's computer. Web Clipper requests a public URL only when the user initiates a capture. Recognized YouTube links use a local placeholder and contact YouTube only after the user opens the link. Users are responsible for their chosen backup and synchronization tools.

## Positioning

Safire is for people who want a polished connected-notes workspace while keeping their writing in durable, portable Markdown files.
