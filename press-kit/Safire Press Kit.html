Product sheet / September 2026

Safire 1.7.0

Good ideas deserve a place to grow.

Safire is a local Markdown workspace for protected writing, connected projects, and practical research. Notes remain ordinary files in a folder you choose, with no required account or cloud service.

PlatformsWindows x64, macOS Apple Silicon and Intel, Linux x64
Storage & licenseLocal Markdown vault / MIT-licensed software

What's new

Writing you can return to

Protected drafts survive navigation and restarts. Compare conflicting edits, keep a separate copy, and recover unfinished notes from Home.

One consistent workspace

Warm paper and forest green by day; deep forest and gold after dark. Editor, projects, graphs, tasks, capture, and Help share the same visual language.

Connected projects

Preview wikilink changes before renaming notes. Explore an isolated Project map or mouse-rotatable 3D Full graph with fullscreen support.

Research worth sharing

Capture sources, record evidence, filter assessments, and create portable Markdown or designed HTML briefs with permitted public source URLs.

Local by design

A rebuildable catalog searches up to 100,000 notes, with explicit capacity notices. Daily notes, tasks, templates, attachments, and keyboard commands support everyday work. Separate optional MCP integrations expose eight Markdown tools and six attributed memory tools.

Safire has no telemetry, hosted sync, or automatic transcript capture. Notes, backups, drafts, and optional memory are plaintext. Web Clipper requests public pages only on user action; external links open in the system browser. Windows and macOS downloads are unsigned.
