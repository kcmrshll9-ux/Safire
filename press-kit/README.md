# Safire Press Kit

This directory preserves the Safire 1.4.0 launch press kit. For the current supported version and release notes, see the root [README](../README.md) and [changelog](../CHANGELOG.md).

## Media inquiries

Open a private security advisory for confidential security matters. For product, review, or media requests, use the repository's issue tracker and label the request `press` when that label is available.

- Repository: https://github.com/kcmrshll9-ux/Safire
- Product support: https://github.com/kcmrshll9-ux/Safire/issues

## Included files

- `Safire Press Kit.pdf` - designed, print-ready press kit.
- `Safire Press Kit.html` - editable source for the PDF.
- `Safire Fact Sheet.md` - product facts and feature summary.
- `Safire Boilerplate.md` - short and long product descriptions.
- `Safire Brand Notes.md` - voice, logo, wording, and usage guidance.
- `Media Contact.vcf` - repository-based contact card.
- `assets/` - approved Safire logo and icon assets.

## Usage

Product facts and screenshots may be used for accurate editorial coverage of Safire. The Safire name, flame mark, and other brand assets remain protected; see the repository's `TRADEMARKS.md` and `LICENSE` files.

Safire is an original product. It is not affiliated with Obsidian or any other third-party notes application.
